#heart-disease-predictor Neural Network
-Its an MIT-OCW assignment Neural network which predicts heart disease with given bio markers

#dataset
-The dataset provided uses 300+ patients with 29 biomarkers features to predict and train.
-the dataset is provided MIT.

#libraries
-Uses keras for model
-Numpys for data manipulation
-pandas for data handling
-matplotlib for graph visualization

#model-architecture
-Input layer has shape of 29 elements in an array
-1 hidden layer of 16 neurons using relu activation
-output layer uses sigmoid for yes/no binary answer
-loss function is binary cross entropy
-optimizer adam
-Using random seed 42 for recreational accuracy


#results
-Model on test performs with accuracy 88% abd los 28%
-Model at best performs 91% accuracy on train data and loss 24%
